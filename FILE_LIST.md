## 🌐 ГОТОВЫЕ МАРШРУТЫ (endpoints)

### Аутентификация
- `GET /` → Редирект на login
- `GET /login` → Страница входа
- `POST /login` → Процесс входа
- `GET /logout` → Выход

### Основные страницы
- `GET /dashboard` → Главная панель
- `GET /tree` → Деревце
- `GET /diary` → Дневник
- `GET /goals` → Цели
- `GET /challenges` → Челленджи
- `GET /partner` → Партнёр
- `GET /settings` → Настройки

### API endpoints
- `POST /api/tree/action` → Действие с деревом
- `POST /api/diary/add` → Добавить запись
- `POST /api/goals/add` → Добавить цель
- `POST /api/goals/complete/<id>` → Завершить цель
- `POST /api/partner/set` → Привязать партнёра
- `POST /api/settings/update` → Обновить профиль
