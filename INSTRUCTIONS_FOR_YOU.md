## 🔐 ЭТАП 2: ПЕРЕМЕННЫЕ ОКРУЖЕНИЯ (5 минут)

### ВАМ НУЖНО СОХРАНИТЬ ДВЕ ПЕРЕМЕННЫЕ:

```
BOT_TOKEN = ваш_токен_бота_123456:ABCDEF...
FLASK_SECRET_KEY = какая_то_длинная_строка_12345
```

**Где найти BOT_TOKEN:**

1. Откройте Telegram
2. Найдите @BotFather
3. Отправьте `/newbot`
4. Ответьте на вопросы
5. Скопируйте токен, который вернёт BotFather

**FLASK_SECRET_KEY:**

Можно любая длинная случайная строка. Например:
```
super_secret_key_with_random_numbers_123456789_abcdef
```

**Сохраните эти две строки в безопасном месте!** 🔒

## 🚀 ЭТАП 4: РАЗВЕРТЫВАНИЕ НА RENDER.COM (10 минут)

### Шаг 1: Зарегистрируйтесь на Render

1. Откройте https://render.com
2. Нажмите "Sign up"
3. Выберите "Continue with GitHub" (удобнее)
4. Авторизуйте приложение

### Шаг 2: Создайте Web Service

1. На главной панели нажмите: "New +" → "Web Service"
2. Выберите: "Deploy an existing repository"
3. Выберите ваш репозиторий `couple-tracker`
4. Нажмите "Connect"

### Шаг 3: Заполните параметры

```
Name:                couple-tracker
Environment:         Python 3
Build Command:       pip install -r requirements.txt
Start Command:       gunicorn app:app
Instance Type:       Free (это бесплатный вариант)
```

### Шаг 4: Добавьте переменные окружения

1. Найдите секцию "Environment"
2. Нажмите "Add Environment Variable"
3. Добавьте две переменные:

| Key | Value |
|-----|-------|
| BOT_TOKEN | ваш_токен_из_BotFather |
| FLASK_SECRET_KEY | длинная_случайная_строка |

### Шаг 5: Создайте сервис

Нажмите кнопку "Create Web Service"

Render начнёт развертывание (это займёт 5-10 минут).

### Шаг 6: Дождитесь завершения

Вы увидите логи развертывания. Когда будет готово, появится ссылка вроде:

```
https://couple-tracker.onrender.com
```

## 🆘 ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

### Ошибка при развертывании на Render

**Проверьте:**
1. Все файлы загружены на GitHub?
2. `requirements.txt` присутствует?
3. `Procfile` правильный?

Посмотрите логи на панели Render:
```
Logs → View All Logs
```

### Ошибка при входе

**Проверьте:**
1. Переменные окружения установлены? (Settings → Environment)
2. BOT_TOKEN правильный?
3. Папка `data` существует?

### Приложение грузится медленно

Это нормально для Free плана. Можно:
1. Ждать (обычно загружается за 30 сек)
2. Перейти на платный план ($7/месяц)

## 💾 СОХРАНЕНИЕ ДАННЫХ

Важно: На Free плане Render данные могут удаляться при перезагрузке.

**Решения:**
1. Переходите на платный план (с персистентным хранилищем)
2. Используйте бесплатный PostgreSQL на Render
3. Сохраняйте в облако (AWS S3, Google Cloud)
