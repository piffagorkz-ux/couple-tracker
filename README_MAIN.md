## 📸 ЧТО ЭТО?

Couple Tracker — это веб-приложение для пар, которое помогает:

- 🌱 **Растить ваше деревце любви** — совместное деревце, которое растет с вашими отношениями
- 📝 **Вести совместный дневник** — записывать ваши самые дорогие моменты
- 🎯 **Достигать целей вместе** — устанавливать и выполнять общие цели
- 🎪 **Принимать челленджи** — забавные задачи для пар
- 💬 **Задавать скрытые вопросы** — вопросы, ответы на которые видны только после обоих
- 🎁 **Вести вишлист** — список желаний и подарков
- 💪 **Вырабатывать привычки** — полезные привычки вместе
- 📊 **Смотреть аналитику** — статистика ваших отношений

## 🚀 БЫСТРЫЙ СТАРТ

### На вашем компьютере (разработка)

```bash
# 1. Установите зависимости
pip install -r requirements.txt

# 2. Установите переменные окружения
set BOT_TOKEN=ваш_токен_телеграма
set FLASK_SECRET_KEY=ваш_секретный_ключ

# 3. Запустите приложение
python app.py

# 4. Откройте в браузере
http://localhost:5000
```

### На облаке (Render.com) — РЕКОМЕНДУЕТСЯ

**Самый простой способ!** Следуйте [DEPLOYMENT_GUIDE.md](./DEPLOYMENT_GUIDE.md) (занимает 10 минут).

Или используйте [QUICK_START.md](./QUICK_START.md) для быстрого развертывания.

## 🎓 КАК ИСПОЛЬЗОВАТЬ

### Первый запуск

1. Откройте приложение
2. Введите ваше имя и Telegram ID (найти: @username_to_id_bot)
3. Попросите партнёра сделать то же самое
4. Введите ID партнёра на странице "👥 Партнёр"
5. Партнёр введёт ваш ID
6. Начните использовать приложение! 💕

```
День 1: Привяжите партнёра
```

## 🆘 РЕШЕНИЕ ПРОБЛЕМ

### Не могу войти

**Проблема:** Ошибка при входе
**Решение:** 
- Проверьте, что вы вводите правильный Telegram ID (число)
- Очистите кэш браузера (Ctrl+Shift+Del)
- Попробуйте другой браузер

### Медленно загружается

**Проблема:** Долгое ожидание
**Решение:**
- На Free плане Render может быть медленным
- Переходите на платный план ($7/месяц)
- Или используйте более мощный сервер

### Данные теряются

**Проблема:** После обновления данные исчезают
**Решение:**
- Используйте платный план Render с персистентным хранилищем
- Или сохраняйте данные в облаке (AWS S3, Google Cloud)

### Бот не работает

**Проблема:** Telegram бот не отвечает
**Решение:**
- Убедитесь, что BOT_TOKEN правильный
- Проверьте, что бот запущен (локально или как вебхук)
- Перезагрузите бота
