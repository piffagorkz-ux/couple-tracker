# 🖤 Couple Tracker Bot v3.0 — ИСПРАВЛЕННАЯ ВЕРСИЯ

Бот для пар с множеством функций: деревце, челленджи, дневник, скрытые вопросы и многое другое!

## ✅ ЧТО БЫЛО ИСПРАВЛЕНО

### 🔴 Критические ошибки:
1. **BOT_TOKEN в коде** → Теперь берется из переменной окружения `BOT_TOKEN` (безопасно!)
2. **Отсутствующее состояние `WAITING_TREE_NAME`** → Добавлено
3. **Функция `photo_id_helper` не определена** → Добавлена
4. **Функция `background_loop` не определена** → Добавлена
5. **Много незаконченных обработчиков** → Все реализованы с базовой функциональностью

## 📋 ТРЕБОВАНИЯ

```bash
pip install python-telegram-bot
```

**Версия Python:** 3.8+

## 🚀 КАК ЗАПУСТИТЬ

### Шаг 1: Получите токен бота
1. Напишите @BotFather в Telegram
2. Создайте нового бота (`/newbot`)
3. Скопируйте токен (выглядит так: `123456:ABCDefGH-ijKlmNOpQRsTuVwXyZ`)

### Шаг 2: Установите токен

**На Linux/Mac:**
```bash
export BOT_TOKEN="ВАШ_ТОКЕН_ЗДЕСЬ"
python lovio.py
```

**На Windows (PowerShell):**
```powershell
$env:BOT_TOKEN="ВАШ_ТОКЕН_ЗДЕСЬ"
python lovio.py
```

**На Windows (CMD):**
```cmd
set BOT_TOKEN=ВАШ_ТОКЕН_ЗДЕСЬ
python lovio.py
```

### Шаг 3: Готово!
Вы должны увидеть:
```
🤖 Бот запущен! Нажмите Ctrl+C для остановки
```
